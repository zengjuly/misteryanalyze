在量化工程中，检测周期（Window Size / Lookback Period）的确定直接决定了策略的命运：周期过长会导致信号严重滞后，错过最佳买卖点；周期过短则会引入大量市场噪声，导致频繁止损。
针对 A 股市场（具有 T+1 与涨跌停限制），确定检测周期不能拍脑袋决定，而必须遵循“时空收敛、多周期共振、结合换手率自适应”的量化标准。以下是确定检测周期的完整落地方案：
------------------------------
## 一、 核心黄金准则：基于“换手率循环”确定基础周期
在 A 股，时间周期（天数）只是表象，资金换手周期才是本质。大盘股换手慢，小盘股换手快。因此，检测周期 $N$ 的核心锚定点是：让筹码完成一次充分的换手（Turnover Cycle）。
## 1. 基础公式（筹码100%换手周期）
设个股过去 20 个交易日的日均换手率为 $\bar{D}$，则一个完整的筹码换手周期 $N_{\text{base}}$ 为：
$$N_{\text{base}} = \frac{100\%}{\bar{D}}$$ 

* 妖股/连板小盘股：日均换手率常达 15% - 20%，其 $N_{\text{base}}$ 约为 5 - 7 个交易日。因此，检测其平台震荡只需看过去 5-10 天的走势。
* 白马股/大盘蓝筹股：日均换手率常在 0.5% - 1.5% 之间，其 $N_{\text{base}}$ 约为 60 - 120 个交易日。检测其平台中枢需要跨越 3-6 个月。

------------------------------
## 二、 针对不同算法路径的周期确定方法
根据上一问提到的两套算法路径，检测周期的确定方法大不相同：
## 路径 A：如果使用“几何两高两低（缠论中枢）”
在几何形态学中，周期由“笔段的平均跨度”决定。

   1. 统计平均笔长：首先用算法在全市场历史数据中，跑出每一个标准“笔”所消耗的平均 K 线根数（通常在 5-9 根 K 线之间）。
   2. 推导中枢检测周期：一个标准的缠论中枢至少由 3 笔重叠构成，加上前后的进入段和离开段，一个完整的几何震荡形态通常需要 $5 \times \text{平均笔长}$。
   3. 最终落地参数：在日线级别，几何检测周期通常固定设为 25 到 40 个交易日。少于 20 天，很难在日线级别真正走出扎实的“两高两低”几何形态。

## 路径 B：如果使用“现代 VAP 统计密度函数”
在统计学模型中，不需要固定死一个天数，而是引入双周期嵌套（快窗口 + 慢窗口）：

* 慢窗口（主中枢背景周期）：固定取 60 个交易日（约一个季度）。用来计算长期的筹码分布密度函数 $f(x)$，锚定市场长线主力的成本控制点（Long-term POC）。
* 快窗口（自适应 ATR 边界周期）：动态取 10 到 14 个交易日。用来捕捉近两周的波动率异动。一旦近两周的 K 线实体全部压缩在慢窗口筹码峰的 1.5 倍快 ATR 境内，即判定平台震荡成立。

------------------------------
## 三、 A 股量化重构：自适应周期计算代码实现
为了不让代码里的 n 变成死参数，我们可以编写一个自适应函数，根据个股近期的活跃度（换手率）动态返回该股当前的最佳检测周期：

import numpy as npimport pd

def calculate_adaptive_lookback(df, min_lookup=10, max_lookup=60):
    """根据A股个股换手率，动态计算自适应震荡检测周期

    :param df: 包含 turnov_rate (换手率，例如5表示5%) 的 DataFrame
    :param min_lookup: 最小检测周期限制（防止妖股周期太短导致统计失真）
    :param max_lookup: 最大检测周期限制（防止大盘股周期太长导致信号完全滞后）
    """
    # 1. 计算过去20天的日均换手率 (避免单日异动干扰)
    df["ma_turnover"] = df["turnover_rate"].rolling(window=20).mean()

    # 2. 根据100%筹码换手率公式计算理论天数
    # A股常有锁仓筹码，我们取 70% 换手作为中枢形成的标准
    df["theoretical_n"] = 70.0 / df["ma_turnover"]

    # 3. 使用 np.clip 将周期限制在合理区间内
    df["adaptive_n"] = (
        df["theoretical_n"].fillna(30).clip(min_lookup, max_lookup)
    )

    # 4. 转换为整数周期
    df["adaptive_n"] = df["adaptive_n"].astype(int)

    return df

## 四、 终极避坑指南：多周期共振（A 股 T+1 必修课）
如果您仅在日线（Daily）单一周期下确定检测窗口，在 A 股由于 T+1 限制，很容易在日线突破当天买入，结果分时图或 30 分钟线已经严重超买，导致收盘炸板被套。
