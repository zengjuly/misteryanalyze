目标

web/pages/1_📈_个股分析.py 中：

只调用一次** feeder.get_daily(...)（长窗口：约 4 年或等价 days）
分析用 daily = long_df 的尾部或同一 DataFrame（已有足够长度即可）
图表用同一份 long_df，删除第二次 get_daily(code, start_date=start4y)

不改 DataFeeder / MysteryLogic 接口；不扩 scope。

唯一修改文件

web/pages/1_📈_个股分析.py

当前问题（对照）

约 110 行：

...
约 235–242 行

两次可能都走网络/缓存，重复。

改法（定点替换）

1. 删除「短 daily + 后面再拉 long」结构

在 with st.spinner(...) 内、from db_manager import MysteryDB 之后，用下面逻辑替换原：

daily = feeder.get_daily(code)
if daily is None or daily.empty:
    ...
last_date = ...

以及后面整段：

kkey = f'kline_long_{code}'
if kkey not in st.session_state:
    ...
    long_df = feeder.get_daily(code, start_date=start4y)
    ...
long_df = st.session_state[kkey]

2. 替换为「一次拉取 + session 复用」

在解析出 code（建议先 code = code.replace('.', '').strip()）且 name 已定后：

    with st.spinner(f"正在分析 {code} {name} ..."):

                long_df = feeder.get_daily(code, start_date=start4y)
                if long_df is None or long_df.empty:
无 start_date 再试一次（兼容部分源忽略 start_date）
                    long_df = feeder.get_daily(code)
                if long_df is not None and not long_df.empty:
                    st.session_state[kkey] = long_df
            long_df = st.session_state.get(kkey)

            if long_df is None or long_df.empty:

分析用同一 DataFrame（指标已在 get_daily 内附带 MA）
            daily = long_df

其后 analysis_cache / weekly / comprehensive_signal_analysis 逻辑不变，继续用变量 daily。

3. K 线段落：禁止再次 get_daily

找到：

其后 _prep_kline、日/周/月 st.tabs、rs.resample(long_df, ...) 不动。

4. 周箱体明细（分析明细区）

daily is long_df，可保持；若担心过长，可改为：

5. 禁止项

本文件内不得再出现第二次 feeder.get_daily(（除入口 fallback：start_date 失败后再调一次无参 get_daily(code)，仍算「同一入口、同一标的一次成功路径」）。
不要改 data_feeder.py / market_data_client.py（除非本页无法传 start_date；若 get_daily 不支持 start_date，入口只写 feeder.get_daily(code) 一次，由源默认天数决定长度）。

若确认 DataFeeder.get_daily 签名为 (code, start_date=None, end_date=None)，用 start_date=start4y；否则只用 feeder.get_daily(code) 一次。
