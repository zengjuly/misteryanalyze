# 详细实现方案：修复股票名称显示 & Excel 报告超链接增强

## 1. 问题分析

### 1.1 个股分析股票名称显示不正确

#### 现象
```
sz.000100 sz.000100 分析完成（最新交易日 2026-08-18）
```
- 输出中出现了两次 `sz.000100`，且**没有股票中文名称**（如“TCL科技”）。
- 原因推测：  
  ① 数据获取/分析流程中，**未正确获取或传递股票名称**，仅使用了带交易所前缀的代码（`sz.000100`）。  
  ② 在日志或输出字符串中，代码被重复拼接（例如同时打印了 `code` 和 `name`，但 `name` 也为 `sz.000100`）。  
  ③ 股票列表数据源中缺少名称字段，或名称字段未被解析。

#### 修复目标
- 确保系统维护一个 **代码 → 名称** 的映射表（可从本地通达信股票列表、AKShare 或数据库获取）。
- 在分析、输出、报告生成时，将 `sz.000100` 转换为 `000100` 或 `TCL科技`，并在显示时使用 **代码 + 名称** 格式，避免重复。

### 1.2 Excel 报告改进需求
1. **汇总报告中的股票代码改为超链接**  
   - 示例：`=HYPERLINK("#个股中航成飞_sz302132!A1", "sz302132")`  
   - 点击后跳转到该股票对应的 sheet 的 A1 单元格。

2. **每个股票 sheet 增加三个超链接**  
   - 首页：跳转回汇总报告。  
   - 前一页：跳转到前一个股票 sheet。  
   - 后一页：跳转到后一个股票 sheet。  
   - 便于在大量股票 sheet 之间快速导航。

## 3. 股票名称显示修复方案

### 3.1 建立全局股票代码-名称映射

**数据源**：
- 从通达信 `tdxgp.zip` 解压得到 `tdxgp.cfg`，包含代码、名称等。
- 或从数据库 `stock_basic` 表读取。
- 或使用 AKShare `stock_zh_a_spot_em()` 获取实时股票列表。

**实现**：
```python
# utils/stock_names.py
import pandas as pd
from functools import lru_cache

@lru_cache(maxsize=1)
def load_stock_name_map() -> dict:
    """返回 {带前缀代码: 名称} 或 {纯数字代码: 名称}"""
    # 尝试从数据库读取
    try:
        from data.db_manager import DBManager
        db = DBManager()
        df = db.get_stock_basic()  # 假设有该方法
        if df is not None and not df.empty:
            # 假设 df 包含 ts_code, name
            return dict(zip(df['ts_code'], df['name']))
    except:
        pass

    # 备选：从本地通达信 tdxgp.cfg 解析
    try:
        import os
        from utils.path_utils import resolve_path
        tdx_dir = resolve_path('TDX_VIPDOC_DIR', 'data/tdx_vipdoc')
        cfg_path = os.path.join(tdx_dir, 'tdxgp.cfg')
        if os.path.exists(cfg_path):
            # 解析 cfg 文件，格式可能为：市场代码 代码 名称 拼音...
            names = {}
            with open(cfg_path, 'r', encoding='gbk') as f:
                for line in f:
                    parts = line.strip().split()
                    if len(parts) >= 3:
                        market = parts[0]   # 0 或 1
                        code = parts[1]
                        name = parts[2]
                        prefix = 'sh' if market == '1' else 'sz'
                        full_code = f"{prefix}.{code}"
                        names[full_code] = name
                        names[code] = name  # 同时存纯数字
            return names
    except:
        pass
    return {}

def get_stock_name(code: str) -> str:
    """根据代码获取名称，若不存在则返回原代码"""
    code_map = load_stock_name_map()
    # 尝试不同格式
    if code in code_map:
        return code_map[code]
    # 去掉前缀再试
    pure_code = code.split('.')[-1]
    if pure_code in code_map:
        return code_map[pure_code]
    # 添加常见前缀再试
    for prefix in ('sh', 'sz', 'bj'):
        full = f"{prefix}.{pure_code}"
        if full in code_map:
            return code_map[full]
    return code  # 返回原代码
```

### 3.2 在分析输出/日志中使用名称

原输出可能类似：
```python
print(f"{code} {code} 分析完成")
```
**修改为**：
```python
name = get_stock_name(code)
print(f"{code} {name} 分析完成（最新交易日 {latest_date}）")
```

若需要同时显示代码和名称，格式应为：`000100 TCL科技` 或 `TCL科技(000100)`，避免重复。

检查 `stock_kline_data` 表中是否包含 `name` 字段？若有，可直接从缓存读取，无需额外映射。但通常 K 线表不存名称，需要单独股票基本信息表。建议在 `stock_basic` 表中增加 `name` 字段，并在数据同步时更新。

## 4. Excel 报告超链接实现方案

### 4.1 汇总报告超链接

**目标**：将汇总 sheet 中的股票代码单元格设置为超链接，格式如 `=HYPERLINK("#个股中航成飞_sz302132!A1", "sz302132")`。在 openpyxl 中，可以直接设置 `cell.hyperlink = "#个股中航成飞_sz302132!A1"`，显示文本为股票代码（或名称）。

**实现步骤**：
1. 在生成汇总报告时，遍历每只股票，获取其对应的 sheet 名称（如 `个股中航成飞_sz302132`）。
2. 设置该行代码单元格的超链接。

**示例代码**（假设使用 openpyxl）：
```python
import openpyxl
from openpyxl.utils import get_column_letter

# 假设 ws_summary 是汇总工作表，股票代码在 B 列（第2列），行号从 2 开始
for idx, stock in enumerate(stock_list, start=2):
    code = stock['code']          # 如 'sz302132'
    name = stock['name']          # 如 '中航成飞'
    sheet_name = f"个股{name}_{code}"  # 对应个股sheet名称
    cell = ws_summary.cell(row=idx, column=2)  # B列
    cell.value = code
    # 设置超链接，注意：sheet名称若包含特殊字符，需加单引号
    cell.hyperlink = f"#'{sheet_name}'!A1"
    cell.style = "Hyperlink"  # 可选样式
```

**注意**：
- 如果 sheet 名称包含空格、括号、连字符等，超链接需用单引号包围：`#'个股中航成飞_sz302132'!A1`。
- 也可以在单元格中写入 Excel 公式：`=HYPERLINK("#个股中航成飞_sz302132!A1", "sz302132")`，但使用 openpyxl 的 `hyperlink` 属性更简洁。

### 4.2 每个股票 sheet 增加首页/前一页/后一页超链接

**步骤**：
1. 在生成每个股票 sheet 时，在固定位置（如 A1、B1、C1）分别放置“首页”、“前一页”、“后一页”超链接。
2. 需要知道所有股票 sheet 的名称和顺序，以便确定前一页和后一页的链接目标。

**实现**：
```python
# 在生成所有股票 sheet 之前，先构建一个有序的 sheet 名称列表
stock_sheet_names = []
for stock in stock_list:
    name = stock['name']
    code = stock['code']
    sheet_name = f"个股{name}_{code}"
    stock_sheet_names.append(sheet_name)

# 遍历生成每个 sheet 时，传入当前索引
for i, sheet_name in enumerate(stock_sheet_names):
    ws = wb.create_sheet(title=sheet_name)
    # 添加导航链接
    # 首页 -> 汇总报告 A1
    cell_home = ws.cell(row=1, column=1, value="首页")
    cell_home.hyperlink = "#汇总报告!A1"
    cell_home.style = "Hyperlink"

    # 前一页
    prev_idx = i - 1
    if prev_idx >= 0:
        prev_sheet = stock_sheet_names[prev_idx]
        cell_prev = ws.cell(row=1, column=2, value="前一页")
        cell_prev.hyperlink = f"#'{prev_sheet}'!A1"
        cell_prev.style = "Hyperlink"
    else:
        # 第一页没有前一页，可留空或禁用
        cell_prev = ws.cell(row=1, column=2, value="")
    
    # 后一页
    next_idx = i + 1
    if next_idx < len(stock_sheet_names):
        next_sheet = stock_sheet_names[next_idx]
        cell_next = ws.cell(row=1, column=3, value="后一页")
        cell_next.hyperlink = f"#'{next_sheet}'!A1"
        cell_next.style = "Hyperlink"
    else:
        cell_next = ws.cell(row=1, column=3, value="")
```

**说明**：
- 首页链接指向汇总报告的 A1 单元格。汇总 sheet 的名称应为 `汇总报告`（或实际名称）。
- 前一页/后一页链接指向相邻股票 sheet 的 A1。
- 链接单元格放在 sheet 的顶部，通常不影响原有数据展示。
- 可根据需要调整位置（如放在 B2 行），但需要确保不与已有内容冲突。

## 6. 注意事项

- **Sheet 名称合法性**：Excel 工作表名称长度限制为 31 个字符，不能包含 `[]:*?/\\` 等字符。若股票名称过长或含非法字符，需截断或替换（例如用 `_` 代替空格）。
- **超链接路径**：内部超链接格式为 `#SheetName!CellRef`，若 SheetName 含空格或特殊字符，需用单引号包围：`#'Sheet Name'!A1`。
- **性能**：若股票数量上千，每个 sheet 都添加三个超链接，对文件大小影响微小，但生成时间可能略增，可接受。
- **兼容性**：使用 openpyxl 生成的文件在 Microsoft Excel 和 WPS 中均可正常打开和跳转。
