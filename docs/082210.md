定位周/月切换触发全量重分析的原因，并核对主升浪 8 项展示实现。# Hermes 执行规范：主升浪 8 项固定展示 + 周/月 K 不重跑分析

唯一文件： web/pages/1_📈_个股分析.py  

根因：全部结果写在 if st.button(...) or _jump_code: 内。点 Tab/Radio 会 rerun，此时 button=False，整块不渲染或用户再点分析 → 感觉「切换周期又全量分析」。

1. 架构（必须）

点「开始分析」→ 算一遍 → 写入 st.session_state['stock_analysis']
任意 rerun（切周/月）→ 若 session 有结果 → 只渲染，不再 get_daily / signal
K 线 radio/tabs → 只改展示周期，读 session 里的 long_df

3. K 线：只切换图，不触发分析

不要用 依赖「仍在 button 块内」的 st.tabs 三开全画（可保留 tabs，但必须在 ctx 渲染区）。

推荐 st.radio（每次只画一张）：

st.subheader("📊 K线图（切换周期仅重绘，不重新分析）")
from indicators.ma_indicators import MAIndicators
from kline_resampler import KLineResampler
rs = KLineResampler()

period = st.radio(
    "周期",
    ["日线", "周线", "月线"],
    horizontal=True,
    key="kline_period_radio",  # 稳定 key，写入 session
)

def _prep_kline(kdf, box_dict, max_bars=1000):
    kdf = kdf.copy()
    if len(kdf) > max_bars:
        kdf = kdf.tail(max_bars)
    if 'MA377' not in kdf.columns:
        kdf = MAIndicators().calculate_ma(kdf)
    if 'EMA20' not in kdf.columns:
        kdf = MAIndicators().calculate_ema(kdf)
    return plot_kline(kdf, title=f"{code} {name}", box=box_dict, max_bars=max_bars)

day_box = {
    '上沿': float(daily['最高价'].tail(20).max()),
    '下沿': float(daily['最低价'].tail(20).min()),
    'POC': ap.get('POC'),
}

if period == "日线":
    st.plotly_chart(_prep_kline(long_df, day_box, 1000), width="stretch")
    st.caption(f"日线: 最近 {min(len(long_df), 1000)} 根")
elif period == "周线":
    wk_long = rs.resample(long_df, 'weekly')
    if wk_long is not None and len(wk_long):
        w_hi = float(wk_long['最高价'].tail(20).max())
        w_lo = float(wk_long['最低价'].tail(20).min())
        st.plotly_chart(
            _prep_kline(wk_long, {'上沿': w_hi, '下沿': w_lo}, 200),
            width="stretch")
        st.caption(f"周线: {w_lo:.2f} ~ {w_hi:.2f}")
    else:
        st.info("周线数据不足")
else:
    mo_long = rs.resample(long_df, 'monthly')
    if mo_long is not None and len(mo_long):
        m_hi = float(mo_long['最高价'].tail(12).max())
        m_lo = float(mo_long['最低价'].tail(12).min())
        st.plotly_chart(
            _prep_kline(mo_long, {'上沿': m_hi, '下沿': m_lo}, 50),
            width="stretch")
        st.caption(f"月线: {m_lo:.2f} ~ {m_hi:.2f}")
    else:
        st.info("月线数据不足")

验收：切「周线」时 不应 出现「正在分析…」spinner，不应 再调 comprehensive_signal_analysis。

若 DataFrame 进 session 有告警，可对 daily/long_df 只保留 OHLCV 列，或分析后写入 st.session_state[f'kline_long_{code}']，ctx 只存 code，渲染时再取。
